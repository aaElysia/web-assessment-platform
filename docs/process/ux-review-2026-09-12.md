# 用户体验（UX）审查报告

- **审查角色**：UX Designer
- **日期**：2026-09-12
- **目标**：让普通用户能（1）快速理解测试、（2）顺利完成、（3）愿意分享反馈
- **审查范围**：首页、知情同意、作答流程（60 题）、结果页、管理端（仪表盘 + 分析）
- **审查依据**：实际源码与组件（`src/app/*`、`src/components/*`、`data/*`），非凭空假设
- **说明**：本次为审查 + 改进方案，**未改动任何代码**；落地清单见最后一节。

## 二、逐项发现与改进方案

### 1. 知情同意（Consent）— 检查四要素

| 要素 | 现状 | 评价 |
|---|---|---|
| Purpose（用途） | ✓ 卡片"研究目的与数据使用"含"用途/匿名/自愿/数据/退出" | 满足 |
| Data usage（数据使用） | ✓ "作答以聚合形式用于统计分析" | 满足 |
| Privacy（隐私） | 🟡 "不收集 PII"已说明，但**未说明数据存于云端数据库、保留期、谁能访问** | 缺口 |
| Non-clinical（非诊断） | ✓ 黄色警告框 + "自愿/退出" | 满足 |

**问题 P0-2（隐私披露不完整）**
用户无法从同意页知道：数据实际存储在受管云数据库（Neon + Vercel 托管）、保留多久、是否有人工访问。这是信任层面的关键缺口，也会影响对"匿名"承诺的可信度。

**改进方案**：
- 在同意卡片增加一条「数据存储与保留」：`数据保存在受管云数据库，与你本机设备分离；我们仅以聚合方式使用，保留期…（建议写明，如"用于本研究期间"或"无限期用于聚合统计"），你提交后无法自行删除单条记录（因匿名无关联标识）。`
- 可选强化：把"非诊断"做成**第二个必勾选框**（"我理解本测评不构成任何临床诊断或医疗建议"），让知情同意更明确、更合规。

### 2. 问卷体验（Questionnaire）

**进度条 ✅**：`ProgressBar` 吸顶、显示 `作答进度 answered/total` + 百分比，且带 `role=progressbar` 与 aria 值——良好。

**问题 P0-3（移动端 Likert 拥挤）**
`LikertScale` 为 `grid-cols-5`，每格内 11px 双行标签（"非常不符合"）。在 320–375px 窄屏下，每格约 56–64px，长标签换行拥挤、点击热区偏小（行高约 44px 临界）。这是移动端完成率的最大风险点。

**改进方案**：
- 窄屏（`<sm`）改用更紧凑的呈现：数字 1–5 为主、标签仅在 `sm:` 以上显示完整文案，或改用 `text-[10px]` 单行缩写（如"很不符/不太/中立/比较/很符合"）。
- 保证每行单选按钮最小点击高度 ≥ 44px（iOS/Android 可点击规范）。
- 反向题（如有需要）可在题号旁加一个低调的"↺ 反向计分"小角标——但**默认不加**，以免提示效应对作答产生引导；仅作为可配置项。

**问题 P1-4（缺"保存并退出"CTA）**
草稿已自动存 localStorage 且有提示文字，但 60 题长流程中**没有显式按钮**让用户安心"稍后再答"。移动端中途退出时用户不确定进度是否保留。

**改进方案**：
- 吸顶进度条区增加一个低调按钮「保存并稍后继续」（点击后滚动到顶部并提示"进度已保存在本设备"）。
- 把现有提示"草稿已自动保存…"做成可消失的成功态徽标（首次保存后显示一次 ✓），增强"已保存"的可感知反馈。

**问题 P2-8（长滚动、无回到顶部/分节跳转）**
60 题单页长滚动，仅有分节标题（scaleName），无分节锚点或回到顶部。

**改进方案**：
- 滚动超过一屏后，右下角出现悬浮「↑ 顶部」按钮。
- 吸顶区分节小导航（点击跳到 O/C/E/A/N 或 AI 五维度的起始题）——可选，先做回到顶部。

**问题 P2-10（提交按钮在页底，答完在顶部看不到）**
`allAnswered` 后提交按钮只在最底部。用户在顶部答完第 1 题后未必会滚到底。

**改进方案**：吸顶进度条在 `allAnswered` 时显示一个低调的「去提交 ↓」链接，点击平滑滚动到底部提交区。

**问题（小）问卷可读性 ✅**：题干为短陈述句（如"我容易感到紧张"），长度适中；反向题按心理测量惯例不标"反向"以避免引导——正确，保留。

### 3. 结果页（Result）

**图表 ✅**：雷达 + 条形均固定 0–5、不归一化、带数值标签与 tooltip——诚实且可核验。
**文案 ✅ / 避免诊断语言 ✅**：`interpretations.json` 全中性，"你更偏好…""情绪体验可能更强烈"而非"你情绪不稳定"——优秀。

**问题 P0-1（无分享 / 反馈入口 —— 与"愿意分享反馈"目标直接冲突）**
全站**没有任何反馈通道**：结果页没有"留下反馈"、没有分享按钮、首页也没有。用户即使满意也无处表达或传播，直接违背本次 UX 目标的第 (3) 条。

**改进方案（轻量、零后端负担优先）**：
- 结果页与首页增加一个「留下反馈」入口：优先用 `mailto:`（如 `反馈邮箱`）或指向一个**第三方表单**（Google Form / 腾讯问卷）的链接——无需自建后端、不触碰数据合规。
- 增加分享：结果页加「复制结果链接」按钮（复制含 `?pid=` 的当前 URL，已有该链接概念，只是没按钮），并可选「分享到…」社交链接。
- 文案引导："觉得有趣？把你的结果链接分享给朋友，或告诉我们你的想法。"

**问题 P1-5（雷达图把"未计分"维度画成 0，视觉上像"极低"）**
`toRadarData` 对 `score===null` 以 0 占位，雷达轴仍落在圆心，读者易误读为"该维度极低"而非"缺失"。虽有图例"(未计分)"文字缓解，但形状本身误导。

**改进方案**：
- 对缺失维度：雷达点用**空心圆 + 虚线连接**或干脆不连该点（断开多边形），并在图下加注"未计分维度仅作示意，不计入轮廓"。
- 或在雷达下方追加一句固定说明，已是 0 占位。

**问题 P1-6（缺少一句中性"个性化小结"，不利于"快速理解"）**
结果页直接进入图表 + 逐维度文字，缺少一段 2–3 句、基于分带标签（非诊断）的自动小结，普通用户需要自己读图归纳。

**改进方案**：在免责声明下方增加一段自动生成小结，例如："你的相对突出倾向是 **开放性、宜人性（接近/高于中点）**，相对不突出的是 **神经质（低于中点）**；AI 态度上你对 **信任** 持保留、**学习意愿** 较高。"——**仅用分带标签与维度名，绝不出现"你属于/你患有"等定性诊断语**。

**问题 P1-7（无"复制结果链接"按钮）**
已有"保存本页链接"的文字提示，但无按钮，移动端复制长 URL 不便。

**改进方案**：加一个 `navigator.clipboard.writeText(window.location.href)` 的「复制结果链接」按钮，带"已复制 ✓"反馈。

### 4. 管理端（Admin）

**清晰度 ✅ / 研究支撑 ✅**：仪表盘有参与漏斗、完成率、端到端耗时中位、各维度均值、指数分布、逐维 n 与 SD、口径说明；分析页有 α（bootstrap）、Pearson r（Bonferroni）、题项分布、CSV 导出、独立复核脚本——对研究分析支撑非常充分。

**增量改进（P2）**：
- 增加**每日完成数趋势**（折线/迷你图），便于试点期监控数据采集进度。
- 分析页可在顶部加一句"当前样本 n=…，距离可作实质结论的阈值还差 …"，把"样本不足"的边界说得更直白。
- 当前 `admin/page.tsx` 仍有"凭据不安全请勿上线"的告警——上线前应确认凭据已切为强随机（Step 10 已生成 `.secrets/production.env`），否则此告警会一直显示。

## 三、优先级改进清单（落地建议）

| 优先级 | 编号 | 改进 | 工作量 | 影响 |
|---|---|---|---|---|
| **P0** | P0-1 | 增加反馈/分享入口（mailto 或第三方表单 + 复制链接按钮） | 小 | 直接命中"愿意分享反馈"目标 |
| **P0** | P0-2 | 同意页补充数据存储位置/保留期披露 | 小 | 信任与合规 |
| **P0** | P0-3 | 移动端 Likert 响应式与点击热区优化 | 中 | 移动端完成率 |
| **P1** | P1-4 | 作答页"保存并稍后继续"CTA + 已保存反馈 | 小 | 降低中途流失 |
| **P1** | P1-5 | 雷达图缺失维度视觉区分（空心/断开） | 小 | 避免误读 |
| **P1** | P1-6 | 结果页中性个性化小结（仅用分带标签） | 小 | 快速理解 |
| **P1** | P1-7 | 结果页"复制结果链接"按钮 | 小 | 分享便利 |
| **P2** | P2-8 | 回到顶部 / 分节跳转 | 小 | 长流程导航 |
| **P2** | P2-10 | 吸顶栏"去提交"链接 | 小 | 提交可达性 |
| **P2** | P2（admin） | 每日完成趋势图 | 中 | 研究监控 |

> 优先级判定：P0 = 直接冲着本次三大目标（尤其"愿意分享反馈"）且成本低；P1 = 明显提升完成率/理解度；P2 = 锦上添花。
> 所有方案均**不改评分/统计计算口径**（与心理测量审查结论一致），只动体验层。
