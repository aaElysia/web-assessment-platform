# 评分系统心理测量学审查报告

- **审查日期**：2026-09-12
- **审查对象**：`src/lib/scoring/*`、`src/lib/questionnaire/*`、`data/question-bank.json`、`data/interpretations.json`、`src/app/api/responses|results/*`、`src/lib/validation.ts`
- **审查方式**：静态代码审查 + 题目逐条核对 + 统计函数数值验证（对照 t 分布分位数表与解析解）
- **结论概览**：评分引擎**实现正确性高、工程严谨**；主要问题集中在**心理测量学合理性/解释效度**层面（无常模、合成指数构念效度、短表信度），均为"解释口径"问题，非计算 bug。

---

## 一、正确性核验（通过项）

### 1. 反向题重编码 —— 正确且一致
- 公式 `recoded = 6 - value`（5 点制）见于 `score.ts:77` 与 `question-bank.json` meta，数学正确。
- 逐条核对两个量表共 **30 道反向题**（Big Five 每域 4 道、AI 每域 2 道），其 `reverse` 标记与题面语义**完全一致**，无错标/漏标。
  - 例：CN4「我对 AI 带来的社会影响总体感到放心」是低担忧陈述 → 标 `reverse:true`，正确。
- 反向仅在**题目级**发生一次；合成指数对 CN **维度分**再做一次域级翻转（`score.ts:173`），与题目级不重叠、不叠加。CN 维度语义「越高越担忧」在全链路一致，**未发现双重翻转 bug**。

### 2. 维度分 = 题目重编码后均值（1–5）—— 符合 BFI 惯例
- `scoreDomain`（`score.ts:103`）对域内有效值取均值，范围恒在 1–5。

### 3. 缺失策略 —— 保守且正确
- 缺失 > 1 题 → `score=null`（incomplete），**不编造分数**（符合 `score.ts:20` 声明）。
- 缺失恰好 1 题 → 用已答均值填补，注释正确指出"填补后均值 == 已答均值"（数值无差别），仅作标识。

### 4. Cronbach's α —— 教科书式正确，规避了头号常见错误
- 先反向重编码再算 α（避免反向题压低 α，这是最常见错误，已规避，`reliability.ts:13`）。
- 采用 **listwise 删除**（不完整被试整行剔除并回报数量），不静默补值。
- 边界情形 `n<2 / k<2 / totalVar=0` 返回 `null` 并给原因，**不返回误导性的 0 或 1**（`reliability.ts:43-69`）。

### 5. 统计函数数值验证（已实跑对照）
| 函数 | 对照基准 | 结果 |
|---|---|---|
| `studentTCdf` | t=1.812,df=10 → 0.95；t=2.228,df=10 → 0.975 | ✅ 通过 |
| `studentTCdf` | t=0 → 0.5 | ✅ 通过 |
| `pearsonR` | 完全正相关→1，完全负相关→-1，零方差→null | ✅ 通过 |
| `pearsonPValue` | r=0.8,n=10 → p≈0.0054 | ✅ 通过 |
| `mean/sampleVariance` | 空/单位样本 → NaN | ✅ 通过 |

### 6. 入口校验与单点算分
- 作答 `value` 被 Zod 限定为 `int 1..5`（`validation.ts:17`），越界值在入库前即被拒，**不会污染分数**。
- 评分仅在服务端由 `scoreAll` 单点计算（`results/[pid]/route.ts:66`），前端拿不到反向映射，避免口径漂移与伪造。

### 7. 解读文案伦理
- `interpretations.json` 措辞中性、非诊断，明确标注"非常模、非临床"；N 与 CN 高分侧不以"好/坏"定性。符合自我洞察类工具的伦理规范。

## 二、合理性与心理测量学问题

### 🔴 严重 / 高优先

**P1. 分带无人群常模，却使用了"相对"措辞，存在误读风险**
- `interpretBand`（`score.ts:85`）的阈值 2.5 / 3.5 是相对于**量表中点 3.0** 的启发式切割，**不是**相对于参照人群百分位。
- Big Five 的标准解释依赖**常模百分位**（如"高于 70% 人群"）。本系统把"中点之上"标为"相对偏高"，易被受访者理解为"比别人高"。
- 缓解：代码注释与结果 API 的 `interpretationNotes` 已声明"非常模"，这是好实践；但**分带标签本身（相对偏低/偏高）仍暗示相对比较**。建议要么把标签改为"低于/接近/高于中点"，要么采集参照样本后产出百分位；并确保**结果页 UI 显式展示"无常模"声明**（不能只躺在 API 字段里）。

**P2. AI 采纳合成指数的构念效度存疑（concern 被当作 favorability 的二分对立面）**
- 公式 `(mean(PU,TR,WA,LA) + (6 - mean(CN))) / 2` 把"对 AI 的担忧"翻转后，与"采纳态度有利面"等权混合。
- 心理测量学上，**对技术的担忧与采纳意愿并非单维两极**：一个人可以"既看好又担忧"（如乐观但关注隐私）。将 CN 折叠进单一"采纳态度"指数，**混淆了两个应独立报告的构念**。
- 建议：CN 作为**独立维度**呈现，不并入合成指数；若保留合成指数，须明确标注为**探索性、仅表面效度**的指数，而非已验证量表。

### 🟠 中等

**P3. 合成指数内各构念的"有效权重"不均等（"等权"声明有歧义）**
- 合成指数 = 50% ×（PU/TR/WA/LA 四域均值） + 50% ×（翻转后的 CN）。
- 其中"四域均值"本身又对 4 个域等权，故 PU/TR/WA/LA 每个**域**占 12.5%，而 CN **域**单独占 50%——**CN 的每题影响力约为任一有利域的 4 倍**。
- `question-bank.json` 的 `weighting` 字段写"equal weight"，实际指"5 个成分等权"，非"每题等权"，措辞易误导。建议澄清或改为按题数加权。

**P4. 缺数据质量筛查（无注意/一致性/测谎题）**
- 自评工具有随机作答、粗心作答风险，但全系统**无任何注意力检测、重复题一致性检验或测谎项**。
- 建议：至少在管理端增加一个"域内外反向-正向一致性"粗筛（如某域内反向与正向题得分显著背离则标记可疑）；最低限度应在披露中说明"未做作答质量筛查"。

**P5. 短表信度天花板（4 题/域的 AI 子维度）**
- AI 各子维度仅 4 题，`Cronbach's α` 在 n=4 时易偏低（常见 0.6–0.7，低于应用界 0.7 的"可接受"线）。
- 好的一面：管理端已能算 α（`reliability.ts`），但**面向用户的报告未展示**。建议：在管理端 analytics 明确展示各维度 α，并对 4 题域的信度局限做标注。

### 🟡 轻微

**P6. 分带阈值（2.5/3.5）为经验值，非数据驱动**
- 在近似对称分布上固定切点属启发式；大量受访者会落入"中等"。可接受，但应保留为"启发式"而非"标准临界值"的表述（代码注释已标注，OK）。

**P7. Likert 等距假设**
- 对 1–5 取均值隐含"等距"假设。人格研究普遍接受参数化处理，属惯例；如追求严谨可补充序贯稳健说明。

**P8. 术语：N 译为"情绪敏感性"**
- 区别于标准 BFI 的"神经质/Neuroticism"。"敏感性"可能被正向误读。非临床场景可接受，但建议在说明中保留英文 Neuroticism 对应，避免歧义。

**P9. 完成度与维度缺失的口径不一致**
- `completionRate = answeredTotal/itemTotal`；若某域缺失 >1 题（该域 null），完成度仍可能高达 58/60≈0.97，看似"完成"却缺一个维度。提交即标 `status=completed` 不区分内部缺失。实践中前端正常收集 60 题，风险低；但建议在结果页对 incomplete 维度做醒目提示（API 已返回 `incomplete` 标志，依赖 UI 落实）。

## 三、结论

- **计算层**：反向重编码、维度均值、缺失策略、Cronbach's α、Pearson 相关与 t 分布 p 值——**实现均正确**，并经数值对照验证。工程上规避了该类系统最常见的几类错误（未重编码算 α、阈值误用、越界值污染）。
- **解释层（主要短板）**：**缺乏人群常模**，导致"偏高/偏低"无参照基准；**AI 合成指数构念效度不足**（担忧与采纳态度被合并）；**短表信度**与**作答质量筛查**缺失。
- **总体判断**：作为**教育性自我洞察工具**是合格且诚实的（已显著声明非常模、非临床）；若希望达到**研究/报告级**可用性，应优先处理 **P1（常模或明确中点相对口径）** 与 **P2（CN 独立呈现）**。

## 四、建议优先级

| 优先级 | 项 | 建议动作 |
|---|---|---|
| 高 | P1 | UI 显式展示"无常模"；分带标签改为中点相对表述，或引入参照样本算百分位 |
| 高 | P2 | CN 作为独立维度报告，合成指数降级为"探索性指数"并加注 |
| 中 | P3 | 澄清"等权"语义或按题数加权 |
| 中 | P4 | 增加反向-正向一致性粗筛 / 披露未做质量筛查 |
| 中 | P5 | 管理端展示各维度 α，标注 4 题域信度局限 |
| 低 | P6–P9 | 维持启发式表述、补充术语对应与 UI 提示 |
